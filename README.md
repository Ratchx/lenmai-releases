# Lenmai releases

ไฟล์ดาวน์โหลดและไฟล์อัปเดตของ **Lenmai** แอปเกมสำหรับ TikTok LIVE บน Windows คนดูคอมเมนต์หรือส่งของขวัญ ตัวละครในเกมจะขยับตาม แล้วนำหน้าเกมไปใส่ OBS หรือ LIVE Studio

## ดาวน์โหลดและติดตั้ง

1. โหลด [`Lenmai-setup.exe`](https://github.com/Ratchx/lenmai-releases/releases/latest/download/Lenmai-setup.exe) (เวอร์ชันอื่นดูได้ที่หน้า [Releases](https://github.com/Ratchx/lenmai-releases/releases))
2. ดับเบิลคลิกเพื่อติดตั้ง แอปจะลงที่ `%LOCALAPPDATA%\Lenmai` ไม่ต้องใช้สิทธิ์ admin เปิดได้จาก Start menu หรือทางลัดบนเดสก์ท็อป
3. เปิดแอปแล้วเข้าสู่ระบบด้วยบัญชี Lenmai

เรื่องที่ควรรู้:
- ตัวติดตั้งยังไม่ได้เซ็น code signing ครั้งแรกที่เปิด Windows อาจขึ้น "Windows protected your PC" ให้กด More info แล้วกด Run anyway
- ต้องมี Microsoft Edge WebView2 Runtime ซึ่งมากับ Windows 11 อยู่แล้ว ถ้าเครื่องยังไม่มี ตัวติดตั้งจะโหลดให้เอง
- ถอนการติดตั้งได้ที่ Settings › Apps › Installed apps › Lenmai › Uninstall

## อัปเดต

Lenmai อัปเดตเองจาก repo นี้
- **ตอนเปิดแอป:** ถ้ามีเวอร์ชันใหม่ แอปจะอัปเดตก่อนเข้าหน้าหลัก แล้วเปิดใหม่ให้เอง
- **ระหว่างใช้งาน:** แอปเช็กทุก 6 ชั่วโมง ถ้าเจอเวอร์ชันใหม่จะขึ้นแถบแจ้งให้กด "อัปเดตตอนนี้" ถ้ากด "ภายหลัง" แอปจะอัปเดตเองตอนเปิดครั้งถัดไป แอปไม่รีสตาร์ทเองระหว่างไลฟ์
- กดเช็กเองได้ที่ ตั้งค่า › ตรวจหาอัปเดต

ไฟล์อัปเดตทุกไฟล์มีลายเซ็นดิจิทัล แอปจะติดตั้งเฉพาะไฟล์ที่เซ็นด้วยกุญแจของ Lenmai เท่านั้น ไฟล์ที่ถูกแก้หรือไฟล์ปลอมจะไม่ถูกติดตั้ง

## ไฟล์ในแต่ละ release

| ไฟล์ | คืออะไร |
|---|---|
| `Lenmai-setup.exe` | ตัวติดตั้ง (ใช้ติดตั้งใหม่และใช้อัปเดต) |
| `latest.json` | ข้อมูลเวอร์ชันพร้อมลายเซ็น ที่แอปใช้เช็กอัปเดต |
